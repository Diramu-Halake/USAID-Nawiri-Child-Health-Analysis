# USAID Nawiri: Child Wasting & Resilience Analysis
## Overview
This repository contains an open-source R statistical workflow developed to analyze bimonthly longitudinal panel data from the USAID Nawiri nutrition program across Isiolo and Marsabit counties in Northern Kenya between September 2021 and September 2023. 

The primary objective of this script is to investigate the immediate drivers of acute child wasting among pastoralist communities, specifically evaluating how seasonal climate shocks and recent illnesses (such as diarrhea) impact child weight-for-height Z-scores, while accounting for protective factors like household milk access.
